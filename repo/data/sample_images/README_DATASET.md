
# Sample Images

This folder contains a small subset of images extracted from the original dataset.

## Purpose

These images are provided for:

- Illustration of the dataset characteristics
- Visualization of different scenarios (lighting, occlusion, environment)
- Demonstration of object annotations (see annotated_example.jpg)

## Notes

- These images do not represent the full dataset
- The complete dataset is not included due to size and privacy constraints
- Image content has been selected to avoid sensitive or identifiable information

## Annotation Example

The file `annotated_example.jpg` contains bounding boxes illustrating object detection annotations.
